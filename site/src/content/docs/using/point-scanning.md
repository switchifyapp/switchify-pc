---
title: Point scanning
description: Choose any point on screen with a moving line, optionally narrowed by a grid, then click, drag or scroll there.
---

Point scanning lets you pick any spot on screen with one switch. Press Select to open [Home](/using/home-menu/), then choose **Point**. If you set *Select starts* to *Last mode used* in Settings, Select goes straight back into it.

## Line only

1. A vertical line moves across the display. Press Select to fix the horizontal position.
2. A horizontal line moves down the display. Press Select to fix the vertical position.
3. An action menu opens at that point, or a click happens by itself if Auto select is on.

## Grid, then line

Narrow the search first:

1. Rows of a grid highlight in turn. Press Select to choose a row.
2. Cells in that row highlight in turn. Press Select to choose a cell. Choose **Back to rows** to go up a level.
3. The lines then run only inside that cell, as above.

The grid can be anything from 2 × 2 to 10 × 10. Switch between the two methods in Settings or from the Switchify item in Home.

## Speed and passes

Line speed runs from very slow to very fast, and you can change it from Home while you work. The lines wrap at the edges. If a phase passes three times without a selection, the scan resets and waits for Select. Holding any switch freezes the position.

## Auto select

With **Auto select** on, a countdown starts at the chosen point and a left click happens when it ends. The delay can be anything from 0.1 to 100 seconds. Press a switch during the countdown to open the action menu instead.

## The action menu

| Action | What it does |
| --- | --- |
| **Left click**, **Right click**, **Double click** | Click at the point. |
| **Scroll** | Up, down, left or right at the point, three wheel steps per press. |
| **Drag** | Start a drag here. Nothing is held yet. Point scanning runs again to choose the destination, then **Drag here** performs it, or **New destination** lets you choose again. |
| **More** | Other clicks at the point (middle, triple, Shift, Ctrl, Alt and Windows or Command click), and the same editing, apps and windows, browser, zoom, media, display and scanning items as Home. |
| **Keyboard** | Open the scanning [keyboard](/using/keyboard/) with focus left where it is. |
| **New point** | Start a fresh scan on the same display. |
| **Home**, **Close menu** | Leave the menu. |

A crosshair marks the chosen point while the menu is open.

## After a selection

By default a click ends the scan and Select starts the next one. In Settings, **After a selection** can be set to keep scanning so the next scan starts by itself.

## Several displays

Point scanning runs on one display at a time. Choose **Next display** or **Previous display** from the Switchify item in Home to move it.

## When the scan stops

If the display or the window in front changes after you have started choosing, the scan cancels so a point is never used on a window it was not chosen over. The keyboard and the mouse panel stay open through such changes.
